供应链扫描说镜像来源可追溯，实际上一份被篡改过构建参数的证明也能通过校验：证明必须把源码提交与构建参数绑定在同一份断言中，构建参数应参与摘要计算，签名必须覆盖包括源码、参数、材料和制品在内的全部断言；材料引用的摘要须与制品实际摘要一致，证明时间戳不得早于源码提交时间，同一制品的多份证明不得互相冲突，批量校验时每个制品都应独立判定。相同证明重复校验应得到相同结果，材料的排列顺序不得改变摘要。

仓库提供证明断言解析、参数与材料摘要、签名校验、制品绑定、时间顺序校验、断言问题检查和批量校验能力。实现只依赖 Python 标准库。
